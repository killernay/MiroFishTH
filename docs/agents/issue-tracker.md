# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues for `killernay/MiroFishTH`. Use `/opt/homebrew/bin/gh-axi` for GitHub operations.

## Conventions

- Create an issue with `gh-axi issue create`.
- Read an issue with `gh-axi issue view <number>`.
- List issues with `gh-axi issue list` and the appropriate state or label filters.
- Comment, label, and close issues with the corresponding `gh-axi issue` commands.

## Pull requests as a triage surface

**PRs as a request surface: no.**

## Skill mapping

- When a skill says “publish to the issue tracker”, create a GitHub issue.
- When a skill says “fetch the relevant ticket”, read that GitHub issue and its comments.
