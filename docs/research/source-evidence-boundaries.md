# Generated content and quoted-source evidence boundaries

## Scope and method

This note traces only first-party repository code for the requested language
boundary. “Quoted source evidence” and “generated content” use the definitions
in [`CONTEXT.md`](../../CONTEXT.md). File-line references below are stable
implementation seams, not a claim that every Zep-derived string is original
source text.

## Determinism and persistence gaps

1. `Project` has no `project_locale` and `SimulationState` has no `run_locale`; both serialise explicit fields to JSON, so adding fields to `to_dict` and `from_dict` is the compatibility seam. ([project.py:57-104](../../backend/app/models/project.py#L57-L104); [simulation_manager.py:80-101](../../backend/app/services/simulation_manager.py#L80-L101); [simulation_manager.py:170-205](../../backend/app/services/simulation_manager.py#L170-L205))
2. Background jobs capture thread-local request locale at start—graph build, simulation monitor, graph-memory updater, and report generation—but this is mutable request context, not an immutable persisted project/run setting. ([graph_builder.py:108-133](../../backend/app/services/graph_builder.py#L108-L133); [zep_graph_memory_updater.py:295-310](../../backend/app/services/zep_graph_memory_updater.py#L295-L310); [report.py:242-270](../../backend/app/api/report.py#L242-L270))
3. Reports read legacy data without a locale field and intentionally reconstruct old serialized records, so absence of locale can identify a legacy artifact that must remain unmodified. ([report_agent.py:2494-2544](../../backend/app/services/report_agent.py#L2494-L2544))

## Decisions for implementation

1. **Provenance representation:** adopt a small, explicit structure (`kind`, `text`, `source_ref`) at action and report-tool boundaries. A boolean `is_quote` is insufficient because simulation-generated posts can be referenced later while still not being uploaded-source evidence.
2. **Evidence policy:** distinguish `uploaded_source_evidence` from `derived_graph_evidence` and `simulation_event_reference`. Only the first qualifies for the requested “Quoted source evidence” label; the latter two can be faithfully shown but must not be represented as original uploaded text.
3. **Validation boundary:** use a deterministic locale validator on *generated fields only*, immediately after every LLM call and before persistence/logging. Retry once with a stronger locale instruction; then fail the task/run/report rather than leaking a disallowed language.
4. **Citation rendering:** require report/chat generation to emit structured citation blocks (or an internal AST) with provenance. Post-processing the final Markdown cannot reliably separate a model quotation from ordinary prose, especially for Thai and English quotation conventions.

## Non-goals established by the evidence trace

- Do not translate or normalize the Zep `data=chunk` upload payload; it is the repository’s only explicit original-source artifact.
- Do not retroactively alter `meta.json` / `full_report.md` records with no locale. The existing loader supports those legacy records directly, so they should be displayed as legacy artifacts.
